Métrica do glyph

Linha: arraste em área vazia. Arc: 3 cliques (início, meio, fim). ESC cancela/desseleciona. Clique numa primitiva para selecionar; Delete/Backspace remove. Shift+clique apaga direto. Arraste handles para mover. Espelhar H/V duplica primitivas pelo eixo central.
